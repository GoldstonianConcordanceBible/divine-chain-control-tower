Required Agent Output Format

Each agent must respond using this structure:

1. Executive Judgment

State the highest-leverage recommendation in 3-5 sentences.

2. Revenue Priority

Identify the most immediate revenue-generating action.

Include:

* action;
* expected benefit;
* required inputs;
* time to execute;
* risk level;
* how to measure success.

3. Ecosystem Priority

Identify the most important ecosystem-building action.

Include:

* GitHub action;
* Discord action;
* Telegram action;
* Substack or YouTube action;
* provenance record needed.

4. Compliance And Language Risk

Flag any wording, structure, launch behavior, or public claim that could create unnecessary legal, financial, platform, reputational, or community risk.

Replace risky language with cleaner language.

5. Evidence Classification

Classify each major claim as one of:

* Verified;
* Corroborated;
* Author-Originated;
* Proposed;
* Future Experiment;
* Unknown.

6. Delphi Scorecard

Score the following from 1-10:

* revenue potential;
* execution speed;
* compliance cleanliness;
* community clarity;
* provenance strength;
* long-term institutional value;
* risk of confusion;
* risk of overextension.

7. Top Five Next Actions

List the five highest-leverage actions in order.

Each action must be specific enough to execute today.

8. Open Questions

List only the questions that materially affect execution.

Do not ask for information that can be reasonably assumed or deferred.

9. Final Control Tower Recommendation

End with one clear recommendation:

Proceed / Pause / Revise / Escalate / Document Only

Explain why.

Mixed-Methods Delphi Rounds

Round 1 — Qualitative Agent Review

Each agent provides open-ended recommendations using the required output format.

Round 2 — Structured Scoring

Each agent scores priorities, risks, and next actions using the Delphi Scorecard.

Round 3 — Consensus And Dissent

Control Tower compares responses across agents.

Consensus items become recommended actions.

Dissenting items are preserved as risk notes, minority reports, or future experiment candidates.

Round 4 — Human Operator Decision

The human operator reviews the agent record and decides:

* execute now;
* revise;
* pause;
* escalate to human expert;
* document only.

Round 5 — Post-Outcome Review

After execution, compare the agent recommendations to real-world outcomes.

Record:

* what happened;
* which agent was closest;
* where all agents missed;
* what evidence was missing;
* what should change in the next round.
